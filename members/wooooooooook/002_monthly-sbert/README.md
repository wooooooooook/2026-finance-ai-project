# monthly-sbert

제목+본문을 결합해 snunlp/KR-SBERT-V40K-klueNLI-augSTS로 임베딩하는 2차 실험.
../001_sbert/의 제목만, 15일자 1개 파일만 방식의 한계(토픽 클러스터가 잘 안 나뉨)를
개선하기 위해, 데이터 소스와 텍스트 입력을 둘 다 바꿨다.

## 데이터

- bigkinds-crawler/downloads의 해당 월 전체 일자 파일을 다 모아서(하루치가 아니라 한 달
  전체, 평균 4만~5만 행) 월별로 3000개씩 무작위 추출 (총 60개월 × 3000 = 18만 건)
- 제목과 본문(이미 최대 200자로 잘려 있는 컬럼)을 "제목. 본문" 형태로 합쳐서 임베딩

## 스크립트

- sample_and_embed.py — 월별로 그 달의 모든 일별 xlsx를 풀링 → 3000개 무작위 샘플링
  (고정 시드) → 제목+본문 결합 → KR-SBERT 임베딩 → embeddings/*.npz 저장. 실행 완료 (18만 건)
- cluster_common.py — UMAP/t-SNE 플로팅 + 품질 지표 유틸. 겹쳐그리기 z-order 버그,
  범례 과다 버그를 여기서 고친 버전 — ../001_sbert/cluster_common.py보다 최신
- cluster_umap_monthly.py — 전체 18만 건 로드 → UMAP/t-SNE 각각 2차원 축소 →
  HDBSCAN 클러스터링 → 연도별/클러스터별 색상 이미지 4장 + CSV + 품질 지표 출력. 실행 완료

## 결과

../001_sbert/와 달리 실제로 의미 있는 토픽 클러스터가 나옴 — 기업 실적 발표, 부고,
기업공시, 인사 발령, 남북관계 뉴스, 부동산 분양 정보 등으로 뚜렷하게 갈라짐.
현재까지 유일하게 완결된 분석.
