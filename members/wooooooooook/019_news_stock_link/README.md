# 019_news_stock_link

BigKinds 경제일간지 기사를 개별 종목에 연결해, 종목마다 값이 다른 뉴스 feature를 만들 수 있는지 확인하는
실험. 월 공통 뉴스 feature(008·009)는 모든 종목에 같은 값이라 Rank IC에 직접 기여할 수 없었다.
이 폴더는 **1단계(연결·커버리지)만** 한다. 수익률과의 관계(2단계), 베이스라인(006) 위의 증분 검증(3단계)은
1단계 정밀도를 확인한 뒤에 진행.

## 1단계: 연결 방식

- 유니버스: `raw/returns`의 보통주 1,086종목(`004730`, `217590` 제외). 기사 구간 2001-01 ~ 2021-12만 사용(test 제외).
- 종목명: `raw/returns/*__company_name.csv`의 **월별 회사명**을 시점별 별칭으로 사용. 이름이 바뀐 종목은 변경 전후 ±1개월을 같은 종목으로 인정.
  그 달 두 종목이 같은 이름이면 모호하다고 보고 제외.
- 정규화: `&`, `㈜`, `(주)` 제거 + 소문자(KRX 종목명에 `&`가 없어서 기사 쪽에서도 지움).
- 매칭 3곳을 따로 센다: `n_title`(제목), `n_org`(`기관` 태그, 쉼표로 나눠 이름이 정확히 같을 때), `n_body`(본문, 원본이 200자 안팎으로 잘려 있음).
  **`n_core` = 제목 ∪ 기관 태그** (본문만 걸린 기사는 우연한 언급이 많아 제외). 후속 분석의 기본 신호는 `n_title`, 보조로 `n_core`.
- 기사 전처리: PREPROCESSING.md 1~4·6번(빈 제목·본문, 분석제외, 제목+본문 중복, 반복 제목).

## 매칭 규칙 (v2, v1 오탐을 보고 추가)

v1 결과(`results/v1_initial/`)에서 "대상"(전체 매칭의 11.4%), "남성", "한창" 같은 일반명사형 2글자 이름과
"LG텔레콤" → `lg` 같은 그룹명 접두, "...상향-sk" 같은 증권사 바이라인, 종목 십수 개를 나열한 시황·공시 기사가 오탐의 주원인이었다.

| 규칙 | 내용 |
|---|---|
| 이름 길이 | 정규화 후 3글자 미만 제외. 예외 허용: `kt`(뒤에 영숫자가 붙으면 다른 이름이라 제외, 예: `ktg`) |
| 뒤 경계 | 이름 바로 뒤에 조사(은·는·이·가·을·를·의·에·에서·으로 등)나 비문자만 허용. 한글이 더 이어지면 복합어라 제외("LG텔레콤", "삼성전자서비스"). 가장 긴 이름이 실패하면 더 짧은 이름으로 되돌아가 재시도 |
| 영문 이어짐 | 이름이 영문으로 끝나고 뒤에 공백+영문·숫자가 이어지면 제외("LG CNS", "SK Telecom") |
| 앞 경계 | 이름 앞이 한글·영숫자면 단어 중간이라 제외 |
| 바이라인 | 제목 끝 "-신한", "- 메리츠", "-sk증권" 같은 증권사 출처 제거 후 매칭 |
| 나열 기사 | 제목에 `시황`, `매매동향`, `동시호가`, `거래소공시`, `시세표`가 있거나, 제목·기관 태그에서 4개 이상 종목이 잡히면 기사 전체 제외 |
| 본문 | 본문만 걸린 기사는 `n_body`로만 기록하고 `n_core`에 넣지 않음 |

## 한계

- 약칭·영문명으로만 쓴 기사는 놓친다. 3글자 미만 이름(예: 2글자 종목) 기사도 놓친다.
- 그룹명으로 불리는 종목(삼성, 한화, 현대 등)은 계열사 기사와 구분하기 어렵다.
- 보통주만 유니버스라 우선주 기사는 보통주로 잡힌다.

## 정밀도 직접 확인하는 법

1. `results/match_samples.csv`를 `results/match_samples_labeled.csv`로 복사.
2. `correct` 열에 기사 제목이 **그 종목에 대한 기사이면 1, 오탐이면 0**을 채움(`matched_names`, `codes` 참고).
3. `uv run python members/wooooooooook/019_news_stock_link/news_stock_link.py report`를 다시 실행하면 층별·전체 정밀도를 출력하고 `precision_by_stratum.csv`에 저장.

## 2단계로 넘어가는 조건 (결과 전에 정해 둠)

- 제목·기관 태그 매칭의 정밀도가 충분히 높을 것(라벨링 표본 기준, 기준은 약 0.8 이상으로 잡고 결과를 보고 재확인).
- 중형·대형 구간에서 `n_core`가 1건 이상인 종목×월 비율이 충분히 남을 것.
- 상위 매칭 이름(`top_matched_names.csv`)에 일반명사형 이름이 없을 것.

아직 실행 안 함(v2). v1(이전 규칙)에서는 중형·대형 커버리지가 높았으나(1건 이상 65%·69%) 오탐이 많아 부풀려진 값으로 판단.
